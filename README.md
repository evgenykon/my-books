# My Books

Читалка FB2 для **Android** и **macOS**: библиотека книг, запоминание места чтения,
управление шрифтами, заметки к строке, выделение текста (копирование, «в заметку»),
пагинация с заголовком (книга, автор, страница, процент) и листание страниц.

## Структура

```
shared/      Kotlin Multiplatform ядро: парсер FB2, модель книги, прогресс чтения
androidApp/  Android-приложение: Kotlin + Jetpack Compose
macos/       macOS-приложение: SwiftUI + CoreText (SwiftPM, ядро как Shared.xcframework)
```

Обе платформы используют **один** парсер FB2 и одну модель документа: книга разбивается
на плоский список блоков (`Block`), позиция чтения — это `(индекс блока, смещение в
символах)`, процент прочитанного считается в ядре (`ReadingProgress`).

### Ядро (`shared`)

- `Xml.kt` — терпимый к ошибкам XML-ридер без внешних зависимостей, декодирование
  UTF-8 / windows-1251 / KOI8-R / Latin-1 / UTF-16, разбор сущностей (`&nbsp;`, `&mdash;`, …).
- `Fb2Parser.kt` — `description/title-info` (название, авторы, аннотация, обложка),
  тела книги (заголовки, абзацы, эпиграфы, стихи, картинки), оглавление из `section/title`,
  тело `name="notes"` в конец книги как «Примечания».
- `Model.kt` — `Book`, `Block`, `TocEntry`, `Position`, `ReadingProgress`.
- `macosMain/BridgeNative.kt` — быстрая конвертация `NSData → ByteArray` и `progressPercent`
  для Swift.

Ядро покрыто тестами (`shared/src/commonTest`) — парсинг, оглавление, индексы блоков,
прогресс, декодирование cp1251 и UTF-8 с BOM.

### Android

- Библиотека: импорт `.fb2` через SAF (без разрешений на хранилище), список с прогрессом,
  удаление книги вместе с заметками.
- Читалка: `HorizontalPager` по страницам, пагинация по реальному layout текста
  (`TextMeasurer`), сохранение позиции первого блока страницы.
- Заголовок: название, автор, «стр. N из M», процент, кнопки содержания, заметок, настроек.
- Выделение: свой `TextToolbar` — «Копировать» и «В заметку» (цитата берётся из выделения).
- Настройки: семейство шрифта, размер, межстрочный интервал, поля, тема (светлая/сепия/тёмная),
  выравнивание по ширине.

### macOS

- Библиотека: импорт `.fb2` через `fileImporter`, список с прогрессом и числом заметок.
- Читалка: пагинация через `CTFramesetter` (CoreText), отрисовка страницы через SwiftUI `Text`,
  навигация стрелками / пробелом / свайпом.
- Заголовок: книга, автор, страница/всего, процент, панели содержания, заметок, настроек.
- Выделение: `textSelection(.enabled)` + ⌘C; контекстное меню абзаца — «Копировать абзац»,
  «Добавить заметку».

## Сборка

Локальные сборки Gradle не выполняются — обе платформы собираются в GitHub Actions.

- **Android**: workflow `Android` — `:shared:testDebugUnitTest` + `:androidApp:assembleDebug`,
  APK в артефакте `mybooks-debug-apk`.
- **macOS**: workflow `macOS` — линковка Kotlin/Native фреймворков (arm64 + x64),
  сборка `Shared.xcframework`, `swift build`, упаковка `MyBooks.app` в артефакт
  `mybooks-macos-app` (плюс `shared-xcframework`).

Локальный запуск macOS-приложения (нужен скачанный `Shared.xcframework` в `macos/`):

```bash
cd macos
./build.sh            # соберёт dist/MyBooks.app
open dist/MyBooks.app
```
