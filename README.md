# My Books

Читалка FB2 для **Windows**, **Android** и **macOS**: библиотека книг, запоминание места чтения,
управление шрифтами, заметки к строке, выделение текста (копирование, «в заметку»),
пагинация с заголовком (книга, автор, страница, процент) и листание страниц.

## Структура

```
shared/      Kotlin Multiplatform ядро: парсер FB2, модель книги, прогресс чтения
androidApp/  Android-приложение: Kotlin + Jetpack Compose
desktopApp/  Windows-приложение: Compose Multiplatform (JVM), ядро как jvm-таргет
macos/       macOS-приложение: SwiftUI + CoreText (SwiftPM, ядро как Shared.xcframework)
```

Все три платформы используют **один** парсер FB2 и одну модель документа: книга разбивается
на плоский список блоков (`Block`), позиция чтения — это `(индекс блока, смещение в
символах)`, процент прочитанного считается в ядре (`ReadingProgress`).

### Ядро (`shared`)

- `Xml.kt` — терпимый к ошибкам XML-ридер без внешних зависимостей, декодирование
  UTF-8 / windows-1251 / KOI8-R / Latin-1 / UTF-16, разбор сущностей (`&nbsp;`, `&mdash;`, …).
- `Fb2Parser.kt` — `description/title-info` (название, авторы, аннотация, обложка),
  тела книги (заголовки, абзацы, эпиграфы, стихи, картинки), оглавление из `section/title`,
  тело `name="notes"` в конец книги как «Примечания».
- `Model.kt` — `Book`, `Block`, `TocEntry`, `Position`, `ReadingProgress`.
- `macosMain/BridgeNative.kt` — быстрая конвертация `NSData → ByteArray` и `progressPercent`
  для Swift.

Ядро покрыто тестами (`shared/src/commonTest`) — парсинг, оглавление, индексы блоков,
прогресс, декодирование cp1251 и UTF-8 с BOM.

### Android

- Библиотека: импорт `.fb2` через SAF (без разрешений на хранилище), список с прогрессом,
  удаление книги вместе с заметками.
- Читалка: `HorizontalPager` по страницам, пагинация по реальному layout текста
  (`TextMeasurer`), сохранение позиции первого блока страницы.
- Заголовок: название, автор, «стр. N из M», процент, кнопки содержания, заметок, настроек.
- Выделение: свой `TextToolbar` — «Копировать» и «В заметку» (цитата берётся из выделения).
- Настройки: семейство шрифта, размер, межстрочный интервал, поля, тема (светлая/сепия/тёмная),
  выравнивание по ширине.

### macOS

- Библиотека: импорт `.fb2` через `fileImporter`, список с прогрессом и числом заметок.
- Читалка: пагинация через `CTFramesetter` (CoreText), отрисовка страницы через SwiftUI `Text`,
  навигация стрелками / пробелом / свайпом.
- Заголовок: книга, автор, страница/всего, процент, панели содержания, заметок, настроек.
- Выделение: `textSelection(.enabled)` + ⌘C; контекстное меню абзаца — «Копировать абзац»,
  «Добавить заметку».

### Windows

- Библиотека: импорт `.fb2` перетаскиванием в окно, через диалог `Ctrl+O` и из командной
  строки (`MyBooks.exe book.fb2`), поиск по названию и автору, удаление книги вместе с заметками.
- Читалка: та же пагинация по реальному layout текста (`TextMeasurer`), колонка ограничена
  по ширине для читаемости на широком экране.
- Навигация: `←` `→`, `PgUp`/`PgDn`, пробел, `Home`/`End`, колесо мыши; `Ctrl` + `+/-` — размер шрифта.
- Заголовок: книга, автор, страница/всего, процент, панели содержания, заметок, настроек
  (боковые панели, а не нижние шторки).
- Выделение: `SelectionContainer` + `Ctrl+C`; правый клик по абзацу — «Копировать абзац»,
  «Добавить заметку».
- Данные: `%LOCALAPPDATA%\MyBooks\library` (`books.json`, `notes.json`, `reader-settings.json`
  и по одному `.fb2` на книгу).

## Шифрованные хранилища

Библиотеку можно держать в зашифрованном виде в **git-ветке** приватного репозитория
GitHub (подход как в `auth-app`): одна ветка — одно хранилище.

- **Имя хранилища = имя ветки**: строчные латинские буквы, цифры и `-`
  (1–40 символов; `main`, `test`, `windows` и т. п. зарезервированы).
- В ветке лежат `vault.enc` — манифест (книги, заметки, прогресс чтения, настройки) — и
  `books/<id>.enc`, по зашифрованному блобу на книгу: добавление одной книги не перезаписывает
  всю библиотеку.
- Шифрование: `PBKDF2-HMAC-SHA256` (200 000 итераций) → `AES-256-GCM`. В файле только
  конверт с параметрами KDF, солью, nonce и шифротекстом — пароль никуда не передаётся.
- Токен GitHub и пароль каждого хранилища лежат в системном хранилище секретов:
  **DPAPI** (Windows), **Android Keystore** (`EncryptedSharedPreferences`), **Keychain** (macOS).
  Пароль спрашивается один раз — при создании хранилища.
- Любое изменение библиотеки (книга, заметка, прогресс, настройки) уезжает в активную ветку
  автоматически примерно через 1,5 с; кнопка «Синхронизировать» делает это вручную.
- Открытие хранилища докачивает книги в локальную библиотеку и применяет заметки, прогресс
  и настройки; уже имеющиеся книги не дублируются.

## Подпись для Windows

`MyBooks.exe` и MSI подписываются самоподписанным сертификатом (`desktopApp/signing/`).
Чтобы Windows показывал издателя, один раз установите в «Доверенные корневые центры
сертификации» файл `mybooks.cer` из релиза (двойной клик → «Установить сертификат» →
«Доверенное корневое…»). Без этого подпись есть, но система пишет «Неизвестный издатель»;
полностью убрать предупреждения SmartScreen может только платный OV/EV-сертификат.

## Обновления на Windows

Приложение при старте (и по «Помощь → Проверить обновления…») смотрит `/releases/latest`.
Если релиз новее, над библиотекой появляется плашка «Доступно обновление X» с кнопкой
«Обновить»: скачивается MSI, приложение закрывается, установщик ставит новую версию и
запускает приложение снова.

Версия MSI растёт вместе с релизом (`version.txt` → `packageVersion = 1.0.N`, где N — номер
патча), иначе Windows Installer не считает установку обновлением и ставит тот же продукт заново.

## Обновления и предупреждение Play Protect

Приложение само проверяет `/releases/latest` на GitHub: показывает баннер и умеет скачать и
установить новый APK (`FileProvider` + «Установка неизвестных приложений»). Проверить вручную
можно в настройках («Проверить обновления»).

APK подписан личным ключом и ставится мимо Google Play, поэтому Play Protect предупреждает об
«опасном приложении» — это нормально для sideload-а: нажмите «Подробнее» → «Всё равно установить»
(либо отключите проверку в Play Защите). Сборки идут из этого репозитория в GitHub Actions.

Настройка: создать **fine-grained personal access token** с правом
**Contents: Read and write** на репозиторий с ветками-хранилищами и вставить его в приложении
в разделе «Хранилища».

## Сборка

Локальные сборки Gradle не выполняются — все платформы собираются в GitHub Actions.

- **Android**: workflow `Android` — `:shared:testDebugUnitTest` + `:androidApp:assembleDebug`,
  APK в артефакте `mybooks-debug-apk`.
- **macOS**: workflow `macOS` — линковка Kotlin/Native фреймворков (arm64 + x64),
  сборка `Shared.xcframework`, `swift build`, упаковка `MyBooks.app` в артефакт
  `mybooks-macos-app` (плюс `shared-xcframework`).
- **Windows**: workflow `Windows` — `:shared:desktopTest` + `:desktopApp:createDistributable`,
  портативный архив `MyBooks/` с встроенной JRE в артефакте `mybooks-windows-zip`;
  `:desktopApp:packageMsi` дополнительно собирает установщик (`mybooks-windows-msi`).

Скриншоты интерфейса Windows-клиента без запуска окна: `gradle :desktopApp:snapshot`
(пишет PNG в `desktopApp/build/snapshots`).

Локальный запуск macOS-приложения (нужен скачанный `Shared.xcframework` в `macos/`):

```bash
cd macos
./build.sh            # соберёт dist/MyBooks.app
open dist/MyBooks.app
```
